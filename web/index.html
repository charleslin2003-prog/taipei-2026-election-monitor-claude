    資料來源

    • Google 新聞搜尋（彙整各家媒體）、台灣事實查核中心、MyGoPen、Cofacts、PTT 八卦板與政黑板。
    • GitHub Actions 每 10 分鐘排程一次抓取，但 GitHub 排程不保證準時，尖峰時段可能延遲或跳過，所以實際間隔約 10 至 60 分鐘。首次部署時以每週區間回補 2026/1/1 以來的新聞。
    • 若上次成功抓取已超過 2 天，下一次會自動把查詢範圍拉回上次成功的日期，補抓中斷期間的新聞。
    • 「回溯」模式以選舉關鍵字逐月往回搜尋，至少到 2022 年 11 月，之後繼續往前，直到連續 6 個月都找不到為止。某個區間的結果達到 Google 單次約 100 則的上限時，會自動把區間切半重查。
    • 每個來源失敗時會重試 2 次；單一來源失敗不影響其他來源，也不會清掉既有資料。
    • 網頁每 60 秒檢查一次是否有新資料，有更新才重新下載新聞檔；切回分頁時也會立即檢查。

    標題修改追蹤

    • 同一則新聞連結若被媒體改了標題，會保留舊標題與發現時間，在「即時新聞」標示「標題曾修改」。只比對文字，忽略標點與空白。
    • 只能偵測收錄之後的修改；收錄前的改動、以及只改內文不改標題的情況無法得知。

    自動分類方式

    • 找出標題中的攻擊用字（批、轟、酸、抹黑、造謠等），依候選人名字出現在用字前後判斷被攻擊方；「遭、被、挨」視為被動句。
    • 候選人批評的對象不是對手（例如業者、中國、選民）時歸為「其他批評」，不計入攻擊統計；批評對手政黨（民進黨、國民黨、市府）時才算攻擊對手，信心標為「低」。
    • 發動陣營依攻擊用字前出現的人名、政黨或「國台辦」等詞判定。
    • 若設定 Claude API 金鑰，會再以模型重新標註，標示為「模型分類」。
    • 只看標題，不判斷內容真假；真假查核請看「人工審核攻防」與「個資查核」。

    限制

    • Google 新聞每次查詢最多約 100 則，回補期間的覆蓋率不是 100%。
    • 網路節目（YouTube、Podcast）與 Threads、Dcard 沒有穩定的公開資料源，只收錄被新聞報導或查核機構記錄的部分。
    • 規則分類會誤判反諷、雙向互批或多人新聞。2026/10/26 人工抽查 25 則攻擊類報導，被攻擊方判斷正確約 6 成，數量請當作趨勢參考。啟用模型分類後可明顯改善。
